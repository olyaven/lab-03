1. Чем x += 5; отличается от x = x + 5;? Есть ли разница в результате?

2. В чём разница между x++ и ++x, если результат сразу используется в выражении
(например, передаётся в Console.WriteLine)?
x++ сначала использует текущее значение x, а затем увеличивает его на 1

++x сначала увеличивает x на 1, а затем использует новое значение

и т.д.)?

4. Что такое «короткое замыкание» в && и ||? Приведите свой пример, где это имеет
практическое значение.
короткое замыкание это "ускоритель вычисления", то есть если у нас есть однозначная ситуация (где первый член в логическом умножении 0 или первый член в логическом сложении 1), то компьютер не тратит время на анализ второго члена
